تعلّم بايثون في سبعة أيام: خطة يومية للمبتدئين

سبعة أيام لا تكفي لإتقان بايثون، لكنها تكفي لتفهم الأساسيات وتكتب برنامجاً صغيراً بنفسك. الشرط الوحيد: ساعة إلى ساعتين كل يوم، وكتابة الأمثلة بيدك بدل الاكتفاء بقراءتها. إن لم تكن قد قرّرت اللغة بعد، فراجع أي لغة تبدأ بها، وللخطة الأوسع على ثمانية أسابيع هذه خطة البداية من الصفر.

اليوم ١: التثبيت وأول برنامج

ثبّت بايثون ومحرراً مثل VS Code، ثم اكتب:

print("مرحبا")
name = input("ما اسمك؟ ")
print("أهلاً", name)

الهدف: أن يعمل البرنامج عندك، وأن تفهم الفرق بين الطباعة print وقراءة المدخل input.

اليوم ٢: المتغيرات وأنواع البيانات

تعلّم الأرقام الصحيحة int والعشرية float والنصوص str، وكيف تحوّل بينها:

age = int(input("عمرك؟ "))
print("بعد سنة سيكون عمرك", age + 1)

تمرين: اطلب من المستخدم رقمين واطبع مجموعهما وحاصل ضربهما.

اليوم ٣: الشروط

if age >= 18:
    print("بالغ")
else:
    print("قاصر")

انتبه للمسافة البادئة في بايثون، فهي جزء من اللغة وليست للتزيين. تمرين: برنامج يخبرك هل الرقم زوجي أم فردي.

اليوم ٤: الحلقات

for i in range(1, 6):
    print(i)

n = 3
while n > 0:
    print(n)
    n -= 1

تمرين: اطبع جدول الضرب لرقم يختاره المستخدم.

اليوم ٥: الدوال

def square(x):
    return x * x

print(square(4))

الدالة تجمع خطوات تكررها في مكان واحد. تمرين: اكتب دالة تعيد الأكبر بين رقمين.

اليوم ٦: القوائم والقواميس

fruits = ["تفاح", "موز"]
fruits.append("برتقال")
prices = {"تفاح": 2, "موز": 1}
print(len(fruits), prices["موز"])

تمرين: احفظ ثلاثة أسماء في قائمة واطبعها واحداً واحداً بحلقة.

اليوم ٧: مشروعك الصغير

اجمع ما تعلمته في لعبة تخمين رقم: يختار البرنامج رقماً بين ١ و٢٠ ويقول لك «أكبر» أو «أصغر» حتى تصيب. إن علقت فارجع لأيام الشروط والحلقات، وهذا طبيعي.

بعد الأسبوع الأول

ستلاحظ أنك ما زلت تحتاج إلى التعمق: الملفات، والأخطاء، والأصناف. إن كنت تفضّل كتاباً عربياً بالترتيب نفسه فهذا تعلّم بايثون من الصفر (٥٣ صفحة)، وفي الصفحة الرئيسية سؤال برمجة يومي تجرّب فيه نفسك.
