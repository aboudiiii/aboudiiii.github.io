تعلّم Java في سبعة أيام: خطة يومية للمبتدئين

Java لغة صارمة قليلاً: تطلب منك كتابة نوع كل متغير وترتيباً واضحاً للكود، وهذا بالضبط ما يعلّمك الانضباط من البداية. خطة الأيام السبعة هذه تعطيك الأساسيات بساعة إلى ساعتين يومياً. وإن كنت ما زلت تختار اللغة فراجع أي لغة تبدأ بها.

اليوم ١: التثبيت وأول برنامج

ثبّت JDK ومحرراً مثل VS Code أو IntelliJ، ثم اكتب في ملف اسمه Main.java:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}

اسم الملف يجب أن يطابق اسم الصنف. التنفيذ يبدأ دائماً من الدالة main.

اليوم ٢: المتغيرات والأنواع

int age = 20;
double price = 3.5;
String name = "Ali";
boolean ok = true;
System.out.println(name + " " + (age + 1));

تمرين: احسب مساحة مستطيل من رقمين تخزّنهما في متغيرين.

اليوم ٣: الشروط

if (age >= 18) {
    System.out.println("adult");
} else {
    System.out.println("minor");
}

انتبه أن النصوص تُقارن بـ equals وليس ==. تمرين: برنامج يحدد هل الرقم موجب أم سالب أم صفر.

اليوم ٤: الحلقات

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

تمرين: اطبع مجموع الأرقام من ١ إلى ١٠٠.

اليوم ٥: الدوال

static int square(int x) {
    return x * x;
}

ضع الدالة داخل الصنف وناديها من main. تمرين: دالة تعيد الأكبر بين رقمين.

اليوم ٦: المصفوفات

int[] nums = {4, 8, 15};
int sum = 0;
for (int n : nums) sum += n;
System.out.println(sum);

الفهرسة تبدأ من صفر. تمرين: اعثر على أكبر رقم في مصفوفة.

اليوم ٧: مشروعك الصغير

اكتب لعبة تخمين رقم باستخدام صنف Scanner لقراءة المدخلات وصنف Random لاختيار الرقم، وكرّر السؤال حتى يصيب اللاعب. إن علقت فراجع يوم الشروط ويوم الحلقات.

بعد الأسبوع الأول

الخطوة الكبيرة التالية هي الأصناف والكائنات (OOP). إن كنت تفضّل كتاباً عربياً يمشي معك بالترتيب فهذا تعلّم Java من الصفر (٦٢ صفحة)، وفي الصفحة الرئيسية سؤال برمجة يومي.
