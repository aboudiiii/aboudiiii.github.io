تعلّم C++ في سبعة أيام: خطة يومية للمبتدئين

C++ لغة قوية قريبة من عتاد الجهاز، ومعظم مواد الجامعات تبدأ بها. لن تتقنها في أسبوع، لكن هذه الخطة تضعك على الطريق الصحيح بالأساسيات، بساعة إلى ساعتين يومياً. وللمقارنة بين اللغات راجع أي لغة تبدأ بها.

اليوم ١: التثبيت وأول برنامج

ثبّت مترجماً مثل g++ أو MinGW، أو استعمل Code::Blocks أو VS Code، ثم اكتب:

#include <iostream>
using namespace std;

int main() {
    cout << "Hello" << endl;
    return 0;
}

الملف ينتقل من النص إلى برنامج عبر الترجمة (compile)، وهذه أول فكرة تميّز C++.

اليوم ٢: المتغيرات والإدخال

int age;
cout << "age? ";
cin >> age;
cout << age + 1 << endl;

تذكّر أن كل جملة تنتهي بفاصلة منقوطة. تمرين: اقرأ رقمين واطبع مجموعهما.

اليوم ٣: الشروط

if (age >= 18) {
    cout << "adult";
} else {
    cout << "minor";
}

تمرين: برنامج يحدد هل الرقم زوجي أم فردي باستخدام عامل الباقي %.

اليوم ٤: الحلقات

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}

تمرين: اطبع جدول الضرب لرقم يدخله المستخدم.

اليوم ٥: الدوال

int square(int x) {
    return x * x;
}

اكتب الدالة قبل main أو أعلن عنها قبلها. تمرين: دالة تعيد الأكبر بين رقمين.

اليوم ٦: المصفوفات

int nums[3] = {4, 8, 15};
int sum = 0;
for (int i = 0; i < 3; i++) sum += nums[i];
cout << sum;

الفهرسة تبدأ من صفر، وتجاوز حدود المصفوفة خطأ شائع لا ينبّهك إليه المترجم. تمرين: اعثر على أكبر رقم في مصفوفة.

اليوم ٧: مشروعك الصغير

اكتب لعبة تخمين رقم: استعمل rand() لاختيار رقم بين ١ و٢٠، واسأل اللاعب حتى يصيب. إن علقت فراجع الشروط والحلقات.

بعد الأسبوع الأول

تابع بالمؤشرات والمراجع ثم الأصناف (OOP). وإن كنت تفضّل كتاباً عربياً بالترتيب نفسه فهذا تعلّم C++ من الصفر (٩٣ صفحة)، وفي الصفحة الرئيسية سؤال برمجة يومي.
